
# Using PHP CodeSniffer (phpcs) #
## The stardard is set to the preferred standard for WPVIP hosting. This can be changed depending on your phpcs settings ##
 - phpcs --standard=WordPress-VIP-Go -sp themes/parasole/theme

To show errors only:
 - phpcs -n --standard=WordPress-VIP-Go -sp wp-content/themes/parasole/theme
